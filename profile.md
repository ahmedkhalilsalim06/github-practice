## One thing I'm confident about using GitHub

## One thing I still find confusing
Branches and merging. I get the basic idea — work on a copy so you don't
break main — but I'm still not 100% sure what happens when two people edit
the same file and Git can't figure out whose version to keep. Merge
conflicts sound scary.

## One rule I think groups should follow when using GitHub
Never push directly to main. Everyone should work on their own branch and
open a pull request, so at least one other person looks at the changes
before they get merged. It keeps one person's mistake from breaking
everyone's work.
